BLIPPVERO HEMSIDA V3
====================

Ändringar i V3:
- Inget personnamn på hemsidan.
- Inget publikt telefonnummer eller publik e-postadress i säljdelen.
- Besökare skickar intresseanmälan direkt via formuläret.
- Blippvero återkommer via telefon eller e-post.
- Telefonsupport anges endast som stöd för befintliga kunder, mån–fre 09:00–18:00.
- Produktbilderna är ersatta med bilder baserade på den faktiska produktmodellen du skickade.
- Mer förklarande och säljande produkttext.

GITHUB
1. Packa upp ZIP-filen.
2. Ladda upp ALLA filer och mappen assets till roten av GitHub-repot Blippvero.
3. Ersätt de gamla filerna.
4. Commit changes. GitHub Pages uppdateras normalt automatiskt.

FORMULÄR – VIKTIGT FÖRSTA GÅNGEN
Formuläret skickas via FormSubmit till kontakt@blippvero.se. Första gången formuläret används skickar FormSubmit ett verifieringsmejl till den adressen. Bekräfta mejlet en gång; därefter skickas nya förfrågningar direkt till inkorgen.

TEST
När du har laddat upp V3:
- Öppna hemsidan i inkognitofönster.
- Skicka en egen testförfrågan.
- Kontrollera kontakt@blippvero.se och godkänn FormSubmit-verifieringen om den kommer.
- Skicka därefter ett nytt test och kontrollera att det kommer fram.
