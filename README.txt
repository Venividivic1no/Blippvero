BLIPPVERO – färdig statisk hemsida

Filer:
- index.html = startsidan
- styles.css = design/färger/layout
- script.js = mobilmeny + årtal
- integritet.html = enkel integritetssida
- assets/product-both.webp = produktbild
- assets/favicon.svg = ikon i webbläsarfliken
- robots.txt + sitemap.xml = grundläggande SEO

Publicering hos STRATO:
1. Skaffa ett webbhotell/hemsideutrymme som stödjer egna filer.
2. Öppna STRATOs filhanterare eller anslut via SFTP/FTP.
3. Ladda upp INNEHÅLLET i denna mapp till webbplatsens webbrot (ofta /htdocs eller motsvarande).
4. Kontrollera att index.html ligger direkt i webbroten.
5. Besök https://blippvero.se.
