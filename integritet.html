Integritet

Integritet på blippvero.se

När du skickar en intresseanmälan eller ett supportärende behandlas de uppgifter du själv väljer att lämna för att Blippvero ska kunna återkomma och hantera din förfrågan.

Vilka uppgifter kan samlas in?

Formuläret kan innehålla företagsnamn, kontaktperson, telefonnummer, e-postadress, önskad kontaktväg, produktintresse och ett frivilligt meddelande. Lämna inte känsliga personuppgifter i fritextfältet.

Vad används uppgifterna till?

Uppgifterna används för att besvara intresseanmälningar, återkomma via telefon eller e-post, lämna produktinformation, hantera support och – om du senare väljer att köpa – administrera kundrelationen.

Hur skickas formuläret?

Blippvero använder en extern formulärtjänst, Web3Forms, för att vidarebefordra formulärdata från webbplatsen till Blippveros inkorg. Webbplatsen har ingen egen kunddatabas.

Hosting och tekniska loggar

Webbplatsen kan hostas via GitHub Pages. Hosting- och formulärtjänster kan behandla tekniska uppgifter som behövs för drift, säkerhet och felsökning enligt sina respektive villkor.

Frågor om dina uppgifter

Om du har frågor om hur dina uppgifter hanteras kan du välja Support i formuläret på startsidan och skriva att ärendet gäller integritet.

Formulärhantering
